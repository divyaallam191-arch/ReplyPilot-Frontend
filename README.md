# ReplyPilot - Frontend

ReplyPilot is an email reply generator that helps users draft replies based on the email content and the tone they choose. This repository contains the frontend built with React.

## What it does

- Allows users to enter the email they want to reply to.
- Lets users select a tone for the reply.
- Sends the email content and selected tone to the backend.
- Displays the generated reply so users can review and use it.

## Technologies Used

- React
- JavaScript
- HTML and CSS
- Vite
- REST API
